# Panamá en Cifras

App web con los principales indicadores macroeconómicos, fiscales, externos, laborales, sociales y demográficos de Panamá, pensada para consultarse desde el celular.

**Fuente de datos:** [MINERPA](https://minerpa.com.pa), Mapa de Información Económica de la República de Panamá, del Banco Interamericano de Desarrollo, con cifras del INEC, la Contraloría General, el MEF y la Superintendencia de Bancos. La pestaña Empleo usa directamente los cuadros de la Encuesta de Mercado Laboral del INEC (2017–2026).

Todo el sitio está en un solo archivo, `index.html`, que se publica con GitHub Pages.
